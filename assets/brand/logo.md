# Chunkyard logo

Generated with the built-in image generation tool. The PNG preserves transparency around the mark. The app and README use copies of the same image.

## Prompt

Use case: logo-brand. Asset: transparent app logo for Chunkyard, a personal Minecraft server manager built in Rust. Create one original sculptural geometric mark: three interlocking cubic voxel blocks arranged into a compact angular C-shaped courtyard, with a deliberate square negative-space opening. The silhouette should evoke a Minecraft chunk and a small industrial yard without copying Minecraft's grass block, creeper or any existing logo. Crisp faceted matte charcoal faces with a concentrated warm ember-orange luminous top edge and restrained copper rim lighting; minimal precise geometry, no busy detail, strong silhouette readable at favicon size. Centered square composition, mark occupies about 80% of canvas. Genuine transparent alpha surrounding the mark, no opaque background, no checkerboard, no ground plane, no shadow outside the silhouette, no words, letters, typography, watermark, mockup or scene. Produce a finished standalone icon.
